# 🛒 Amazon Clone
An Amazon Homepage Clone built with **HTML & CSS**. I recreated the Amazon homepage UI with navbar, hero banner, product cards & footer.

## 🔗 Live Demo
https://amazone-clone-eosin-two.vercel.app/

## ✨ Features
- 🔍 Amazon-style Navbar with Search Bar
- 🖼️ Hero Banner Section
- 🛍️ Product Cards & Categories
- 📱 Responsive Layout
- 🎨 Pixel-Perfect Amazon UI Design

## 🛠️ Tech Stack
- **HTML** - Structure
- **CSS** - Styling & Layout

## 🚀 How To Run
# 1. Clone the repo
git clone https://github.com/akankshama97/Amazon-Clone.git

# 2. Open index.html in browser
